# Multiphase Generation with <think> Blocks - Implementation Summary

## Changes Made to backend_request_func.py

Modified `_multiphase_generation_with_budget()` function to implement structured thinking with early stopping detection.

## New Behavior

### Phase 1: Thinking Phase
1. **Prompt starts with `<think>` tag**: Prompt is formatted as `{original_prompt}\n\n<think>`
2. **Budget enforcement**: Model generates up to `t` tokens (from token_budget)
3. **Early stopping detection**:
   - Added `</think>` as a stop sequence
   - If model emits `</think>` before budget exhausted → stops immediately
   - If budget exhausted without `</think>` → forcibly appends `</think>`
4. **Tracking**: `stopped_early` flag tracks whether model naturally closed thinking block

### Phase 2: Solution Phase
1. **Max tokens**: Set to **15 tokens** (configurable via `MAX_TOKENS_ANSWER`)
2. **Prompt format**: `{thinking_prompt}{thinking_output}\n\nFinal Answer: \boxed{`
3. **Generation**: Model generates final answer in boxed format

## Key Configuration Changes

```python
MAX_TOKENS_THINKING = request_func_input.token_budget
MAX_TOKENS_ANSWER = 15  # Solution phase max tokens (was 10)
```

## Payload Changes

### Thinking Phase Payload
```python
"stop": ["</think>"],  # NEW: Stop if model emits </think>
```

### Answer Phase Payload
```python
"stop": ["}", "</s>", "<|endoftext|>", "<|im_end|>"],  # Added "}" to stop at boxed end
```

## Output Format

Generated text structure:
```
<think>
[thinking content generated by model]
</think>

Final Answer: \boxed{[answer]}
```

## Logging Enhancements

### Standard Output Log
Added field:
```
Early stop (</think> emitted): True/False
```

### Full Output Log
Enhanced with:
- Separate sections for thinking and answer outputs
- Early stop status
- Max tokens for answer phase
- Full generated text with proper formatting

## Benefits

1. **Explicit thinking structure**: `<think>` blocks make reasoning transparent
2. **Natural stopping**: Model can decide when thinking is complete
3. **Budget enforcement**: Hard cap prevents runaway generation
4. **Early transition**: Efficient token use when model finishes thinking early
5. **Predictable solution length**: 15-token limit for final answer

## Usage

No changes needed to calling code - works with existing token budget setup:

```python
# Token budget is set per-problem in budgets file
python run.py \
    --run-with-budgets \
    --budgets-file budgets_concise_baseline.csv \
    --dataset GSM8K_benchmark.json
```

## Testing Recommendations

1. **Verify early stopping**: Check logs for `Early stop (</think> emitted): True` cases
2. **Check budget enforcement**: Confirm thinking tokens ≤ budget
3. **Validate answer format**: Ensure `\boxed{}` extraction works correctly
4. **Monitor solution length**: Verify answer phase uses ≤ 15 tokens
5. **Compare accuracy**: Test against previous multiphase implementation
